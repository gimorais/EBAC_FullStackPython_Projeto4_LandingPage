# Landing Page — Os Jogos Vorazes

Landing page temática inspirada no universo de **Jogos Vorazes**, desenvolvida com foco em **identidade visual**, **responsividade** e **interatividade em front-end**.

## Demonstração

Acesse o projeto online:  
https://ebac-full-stack-python-projeto4-lan.vercel.app/

## Sobre o projeto

Este projeto foi desenvolvido como uma landing page promocional inspirada em uma plataforma fictícia de streaming ambientada no universo de **Panem**.

A proposta foi criar uma interface visualmente marcante, com seções bem definidas, navegação intuitiva, layout responsivo e interações em JavaScript para enriquecer a experiência do usuário.

## Objetivos do projeto

- Praticar a construção de interfaces web responsivas
- Trabalhar a organização de estilos com **SCSS**
- Utilizar **JavaScript** para interações na interface
- Aplicar **Gulp** para automação do fluxo de build
- Criar uma página com identidade visual forte para apresentação em portfólio

## Funcionalidades

- Hero section com destaque principal
- Navegação por seções da página
- Alternância entre abas de conteúdo
- Menu responsivo
- FAQ com expansão e recolhimento de respostas
- Seção de livros e filmes
- Seção de dispositivos compatíveis
- Rodapé com links e informações complementares
- Layout responsivo para diferentes tamanhos de tela

## Estrutura do projeto

```bash
src/
├── images/
├── styles/
├── main.js
└── index.html
```

Os estilos foram organizados em arquivos SCSS separados por seções da interface, facilitando a manutenção e a escalabilidade do projeto.

## Build e automação

O projeto utiliza **Gulp** para automatizar tarefas do fluxo de desenvolvimento, como:

- compilação de arquivos SCSS para CSS
- compressão do CSS final
- organização dos arquivos na pasta de distribuição
- cópia de imagens para build final

## Como executar o projeto localmente

### 1. Clone o repositório

```bash
git clone https://github.com/gimorais/EBAC_FullStackPython_Projeto4_LandingPage.git
```

### 2. Acesse a pasta do projeto

```bash
cd EBAC_FullStackPython_Projeto4_LandingPage
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o ambiente de desenvolvimento

```bash
npm run dev
```

### 5. Gere a build do projeto

```bash
npm run build
```
